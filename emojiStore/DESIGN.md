# Design System & Color Palette

## Dark Theme (Slate)

We use the Tailwind CSS **Slate** scale for a cool, modern dark interface.

| UI Element             | Tailwind Class     | Description                                   |
| :--------------------- | :----------------- | :-------------------------------------------- |
| **Page Background**    | `bg-slate-950`     | The deepest shade for the main canvas.        |
| **Cards / Sections**   | `bg-slate-900`     | Slightly lighter background for containers.   |
| **Borders / Dividers** | `border-slate-800` | Subtle separation lines.                      |
| **Primary Text**       | `text-slate-100`   | Headings and main readable content.           |
| **Secondary Text**     | `text-slate-400`   | Metadata, subtitles, and less important text. |

## Action Colors

Use these for buttons, links, or interactive elements to make them pop against the dark background.

- **Primary Action**: `text-sky-400` or `text-indigo-400`
